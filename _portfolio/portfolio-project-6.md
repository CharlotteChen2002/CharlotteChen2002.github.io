This project presents the design, implementation, verification, and synthesis of a 64-tap 16-bit finite impulse response (FIR) filter using a dual-clock architecture. The system achieves real-time 10 kS/s throughput with a 10 kHz input clock and a 1 MHz core clock, incorporating fixed-point arithmetic, robust clock domain crossing, and a sequential multiply-accumulate datapath optimized for area and power efficiency.
